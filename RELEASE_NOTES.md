# Release Notes

## v1.0.0

Syok Dub Siren GB v1.0.0 is the first public release.

### Download

Download the ROM from the release assets:

```text
syok-dub-siren-gb.gb
```

### Summary

- Dub siren homebrew ROM for the original DMG Game Boy.
- Built with GBDK-2020.
- Direct controls for pitch, LFO depth, LFO rate, and LFO waveform.
- LFO waveform display with depth-scaled vertical amplitude.
- ROM header title: `SYOKDUBSIRENGB`.
