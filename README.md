# Game Boy Dub Siren

GBDK-2020 で作成した DMG Game Boy 向けダブサイレン ROM です。

## Build

GBDK-2020 の `lcc` に PATH が通っている環境では次を実行します。

```sh
make
```

PATH を通していない場合は `GBDK_HOME` を指定します。

```sh
make GBDK_HOME=/path/to/gbdk
```

出力 ROM:

```text
build/gb_dub_siren.gb
```

## 操作対応表

パラメータ選択方式を採用しています。上下キーで PITCH / DEPTH / SPEED の調整対象を選び、左右キーで選択中の値を変更します。

| 元の操作子 | Game Boy割り当て | 実装挙動 |
|---|---|---|
| ゲート | A | 押している間だけ発音 |
| キル | なし | Game Boy版では未使用 |
| LFO一時停止 | Select | 押している間 LFO の角度更新を停止 |
| 波形切替/手動発音 | Start | 約230ms未満の短押しで LFO 波形切替。長押し中は強制発音 |
| POT1 ピッチ | Up / Downで選択、Left / Rightで変更 | ベースピッチを増減 |
| POT2 LFO深さ | Up / Downで選択、Left / Rightで変更 | LFO 深さを増減 |
| POT3 LFO速度 | Up / Downで選択、Left / Rightで変更 | LFO 速度を増減 |

画面上の `>` が現在選択中のパラメータです。B ボタンには機能を割り当てていません。LFO WAVE 欄には選択中のLFO波形を4行x20列のミニ波形として表示し、現在位置を `@` で示します。

## 仕様メモ

- Game Boy APU のチャンネル1を直接操作します。
- `NR10`-`NR14` と `NR50`-`NR52` を使用します。
- 周波数は `131072 / (2048 - freq)` Hz の関係から 11bit レジスタ値へ変換します。
- LFO は 256 ステップのルックアップテーブル/整数演算で、SINE / SQUARE / SAW / REV SAW を実装しています。
- 発音開始/終了は NR12 の上位ニブルを数フレームごとに変更して簡易フェードします。
- B ボタンによるキル機能は削除しています。

## 既知の制限

- Arduino 版の Timer1 ISR による 128 段階フェードとは完全一致ではなく、Game Boy APU に合わせた 16 段階音量フェードです。
- 元のアナログポットと異なり、パラメータは方向キーで段階的に変更します。
- サイン波は軽量化のため 64 値クォーター波形をミラーして 256 ステップ化しています。
- 実機/エミュレータの APU 差により、音量フェードや再トリガの聴こえ方が多少変わります。
